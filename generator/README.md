# PROPHOTO — генератор карусельних постів

Один текстовий файл + папка з фото → готові слайди 3240×4050 (4:5) для Instagram.

## Запуск

```bash
pip3 install pillow
python carousel.py post.txt --photos ./photos --out ./out --jpg --preview
```

* `--jpg` — віддати JPG (q95) замість PNG
* `--preview` — додатково зібрати контакт-лист `preview.jpg` для швидкого перегляду

## Формат `post.txt`

```
# ЗЙОМКА НА БІЛОМУ ФОНІ              ← заголовок обкладинки (Bold 200)
> від *чорного* до чисто білого       ← саблайн (Light 100); *слово* = червоне підкреслення
cta: дізнатись тонкощі **роботи зі світлом**   ← необов'язково, є дефолт
photos: a.jpg, b.jpg, c.jpg           ← 3 фото обкладинки

## ЩОБ З БІЛОГО ОТРИМАТИ ТЕМНО-СІРИЙ ФОН     ← нова секція = внутрішні слайди
layout: A                              ← необов'язково: A або B (за замовчуванням чергуються A, B, A…)
photos: d.jpg, e.jpg, f.jpg            ← 3 фото секції (якщо нема — беруться з обкладинки)
1. світло збоку — чим **ближче до фону,** тим світліше фон;
2. принцип: чим **менше світла потрапляє на фон,** тим він темніший;
- можна й без номера — пронумерує сам
```

### Жирний / тонкий
* `**текст**` → Bold, решта → Light. Усе автоматично в UPPERCASE.
* Якщо в пункті немає `**`, генератор сам виділить жирним ключову фразу —
  усе до першої коми, тире, дужки або двокрапки (це саме та логіка, що у шаблоні:
  жирним — суть/параметр/дія, тонким — пояснення).

### Обкладинка
Якщо `>` саблайн не задано, а заголовок довший за 4 слова — перші 3 слова стануть
заголовком, решта — саблайном.

## Що робить автоматика

| Крок | Логіка |
|---|---|
| Пагінація | Пункти секції розкладаються на мінімальну кількість слайдів так, щоб текст вміщався у текстову зону шаблону; між слайдами баланс за кількістю пунктів. Заголовок і фото секції повторюються на кожному її слайді (як POST_3 → POST_4). |
| Layout A | заголовок → фото → список; якщо в один стовпчик не влазить, а пунктів ≥ 4 — дві колонки (як POST_4) |
| Layout B | заголовок → список → горизонтальні лінії → фото (як POST_2) |
| Постійне | блік, пунктирні рейки з крапками, червона закарлючка під заголовком, стрілки, навігація «лінія–трикутник–пунктир», останній слайд з іконками й логотипом |
| Фото | вирізаються по центру під розмір рамки (cover-crop); центральне фото зверху, як у шаблоні; відсутні — темний плейсхолдер |

## Файли

```
carousel.py          — генератор
assets/fonts/        — KyivType Sans Light / Bold / Heavy (вільна ліцензія, Д. Растворцев)
assets/svg/          — закарлючка, підкреслення, стрілки, іконки
assets/logo_wide.png — логотип PROPHOTO
demo/post.txt        — приклад посту (ваш контент про білий фон)
demo/photos/         — тимчасові фото-плейсхолдери
demo/out/            — результат прикладу
```

## Ідеї для наступного кроку
* Веб-форма (вставив текст → перетягнув фото → скачав ZIP) поверх цього ж рушія.
* Авто-розмітка жирного через Claude API замість евристики — для нестандартних текстів.
* Вибір закарлючка / підкреслення під заголовком, варіант обкладинки з іншим розкладом фото.

## Завантаження в Google Drive

```bash
python drive_upload.py ./out --folder 1ZAX3ag3joaKvTwf6D-LzHkqFDw9z9c_o --name "Назва поста"
```
Створює підпапку в папці «ПОСТИ» і кладе туди всі слайди. Одноразове налаштування
(OAuth-клієнт Google, `credentials.json`) описане у шапці `drive_upload.py`.

Повний конвеєр одним рядком:
```bash
python carousel.py post.txt --photos ./photos --out ./out --jpg && python drive_upload.py ./out --folder 1ZAX3ag3joaKvTwf6D-LzHkqFDw9z9c_o --name "Зйомка на білому фоні"
```
